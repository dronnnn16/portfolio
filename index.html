The basics

Every point has an address. The address is two numbers: \((x, y)\).

  • The x-axis is the flat line. It goes left and right.
  • The y-axis is the standing line. It goes up and down.
  • They cross at the origin, \(O(0, 0)\).
  • \(x\) says how far left or right. \(y\) says how far up or down.
  • Right and up are \(+\). Left and down are \(-\).
Tap anywhere

Tap the graph. You will see the point's address and its quadrant.

Distance formula

How far apart are two points \(A(x_1, y_1)\) and \(B(x_2, y_2)\)?

\[ d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2} \]

In words: x-gap squared, plus y-gap squared, then square root.

Think of it like this

You live in a city of square blocks. To go from A to B, you walk 3 blocks right. Then 4 blocks up.

A bird does not walk. It flies straight. That straight line is the shortcut.

This is Pythagoras: \(\text{shortcut}^2 = 3^2 + 4^2 = 25\). So shortcut \(= 5\).

Example: find the distance between \(A(1, 2)\) and \(B(4, 6)\).

  1. x-gap: \(x_2 - x_1 = 4 - 1 = 3\)
  2. y-gap: \(y_2 - y_1 = 6 - 2 = 4\)
  3. Square and add: \(3^2 + 4^2 = 9 + 16 = 25\)
  4. Square root: \(d = \sqrt{25} = 5\)

Answer: 5 units

Special case: distance from the origin

One point is \(O(0, 0)\). The zeros vanish:

\[ d = \sqrt{x^2 + y^2} \]

Example: \(P(3, 4)\) is \(\sqrt{9 + 16} = 5\) units from the origin.

Two exam uses

Are 3 points on one line?

Find AB, BC and AC. If the two small ones add up to the big one, the points are collinear (on one line).

\(AB + BC = AC\) means yes.

Example: \(A(1,1), B(2,2), C(3,3)\). \(AB = \sqrt2\), \(BC = \sqrt2\), \(AC = \sqrt8 = 2\sqrt2\). \(\sqrt2 + \sqrt2 = 2\sqrt2\). Yes, collinear.

Same distance from two points

Call the unknown point \(P\). Write \(PA = PB\). Square both sides so the \(\sqrt{\ }\) goes away. Then solve.

Example: point on the x-axis, same distance from \(A(2,-5)\) and \(B(-2,9)\). Take \(P(x, 0)\).

\((x-2)^2 + 25 = (x+2)^2 + 81\)
\(-4x + 29 = 4x + 85\)
\(x = -7\). So \(P(-7, 0)\).

Section formula

A point \(P\) cuts the line from \(A(x_1, y_1)\) to \(B(x_2, y_2)\) in the ratio \(m : n\). Where is \(P\)?

\[ P = \left( \frac{m x_2 + n x_1}{m + n},\ \frac{m y_2 + n y_1}{m + n} \right) \]

Cross over: \(m\) goes with B's numbers. \(n\) goes with A's numbers.

Think of it like this

A chocolate bar goes from A to B. You break it in the ratio \(2 : 3\). Your friend gets 2 pieces. You get 3 pieces.

\(P\) is the cut. \(AP : PB = 2 : 3\). So \(P\) is closer to A.

A bigger \(m\) pushes \(P\) towards B. That is why \(m\) multiplies B's numbers.

Example: find P dividing \(A(4, -3)\) and \(B(8, 5)\) in the ratio \(3 : 1\).

  1. Write it down: \(m = 3,\ n = 1\). \(x_1 = 4,\ y_1 = -3\). \(x_2 = 8,\ y_2 = 5\).
  2. x: \(\dfrac{3(8) + 1(4)}{3 + 1} = \dfrac{24 + 4}{4} = \dfrac{28}{4} = 7\)
  3. y: \(\dfrac{3(5) + 1(-3)}{4} = \dfrac{15 - 3}{4} = \dfrac{12}{4} = 3\)

Answer: \(P(7, 3)\)

Midpoint: ratio 1 : 1

The midpoint is the exact middle. Add, then halve.

\[ M = \left( \frac{x_1 + x_2}{2},\ \frac{y_1 + y_2}{2} \right) \]

Example: midpoint of \((-2, 3)\) and \((6, -7)\).

  1. x: \(\dfrac{-2 + 6}{2} = \dfrac{4}{2} = 2\)
  2. y: \(\dfrac{3 + (-7)}{2} = \dfrac{-4}{2} = -2\)

Answer: \((2, -2)\)

Trick: "find the ratio" → take \(k : 1\)

Do not use two unknowns. Use \(m = k\) and \(n = 1\). Solve for \(k\) using just the x-part (or just the y-part).

Example: in what ratio does \(P(0, 3)\) divide \(A(-2, 1)\) and \(B(4, 7)\)?

  1. Let the ratio be \(k : 1\).
  2. x-part: \(\dfrac{k(4) + 1(-2)}{k + 1} = 0\)
  3. So \(4k - 2 = 0\), which gives \(k = \dfrac{1}{2}\).
  4. \(\dfrac{1}{2} : 1\) is the same as \(1 : 2\).
  5. Check y: \(\dfrac{\frac12(7) + 1}{\frac12 + 1} = \dfrac{4.5}{1.5} = 3\). Correct.

Answer: \(1 : 2\)

Trick: an axis does the cutting

  • x-axis divides the line? The cut point is on the x-axis, so put \(y = 0\).
  • y-axis divides the line? The cut point is on the y-axis, so put \(x = 0\).

Example: in what ratio does the x-axis divide \(A(2, -3)\) and \(B(5, 6)\)? Find the point too.

  1. Let the ratio be \(k : 1\). On the x-axis, \(y = 0\).
  2. y-part: \(\dfrac{k(6) + 1(-3)}{k + 1} = 0\)
  3. So \(6k - 3 = 0\), which gives \(k = \dfrac12\). Ratio \(= 1 : 2\).
  4. x with \(1 : 2\): \(\dfrac{1(5) + 2(2)}{3} = \dfrac{9}{3} = 3\)

Answer: \(1 : 2\), point \((3, 0)\)

Points of trisection: ratios 1 : 2 and 2 : 1

"Trisect" means cut into 3 equal parts. That needs 2 cut points. The first is at \(1 : 2\). The second is at \(2 : 1\).

Example: trisection points of \(A(1, -2)\) and \(B(7, 4)\).

  1. P at \(1 : 2\): x \(= \dfrac{1(7) + 2(1)}{3} = \dfrac{9}{3} = 3\), y \(= \dfrac{1(4) + 2(-2)}{3} = \dfrac{0}{3} = 0\)
  2. Q at \(2 : 1\): x \(= \dfrac{2(7) + 1(1)}{3} = \dfrac{15}{3} = 5\), y \(= \dfrac{2(4) + 1(-2)}{3} = \dfrac{6}{3} = 2\)
  3. Check: A(1, −2) → (3, 0) → (5, 2) → B(7, 4). Each step is +2, +2. Equal parts.

Answer: \((3, 0)\) and \((5, 2)\)

Common mistakes

These cost marks every year. Do not be that student.

  • Sign errors with negatives

    Put negatives in brackets. \(4 - (-3) = 7\). Writing \(4 - 3 = 1\) is wrong.

  • Squaring a negative

    \((-3)^2 = 9\). It is always positive. Never \(-9\).

  • Swapping m and n

    \(m\) goes with B's numbers \(x_2, y_2\). \(n\) goes with A's numbers \(x_1, y_1\). It crosses over.

  • Forgetting the square root

    You got \(9 + 16 = 25\). The answer is \(\sqrt{25} = 5\), not 25.

  • Midpoint: subtracting instead of adding

    Midpoint adds and halves. Distance subtracts. Do not mix them up.
