Short-form (9:16) clips for the hero carousel. Slots are set in data/site.ts (heroReels).
- ai-audio.mp4 / ai-audio.jpg: AI Audio reel. It's the only reel so far, so it fills
  all 8 slots, each starting at a different point in the clip.
To add a reel: drop the .mp4 (and a .jpg poster) here and point a slot at it in data/site.ts.
Export tip: H.264 MP4, 720x1280, 30fps, no audio (the carousel plays muted), under ~3 MB.
