Spot the pattern

Before any maths words, just look. In each list below, how do you get from one number to the next?

Riya's piggy bank

She starts with ₹50 and puts in ₹10 every week.

Taxi fare

₹30 for the first km, then ₹12 for every extra km.

Rocket countdown

Each second, the number goes down by one.

Did you see it? In every list, you get the next number by adding the same amount each time. In the countdown, the amount you add is −1, which is the same as taking away 1.

That “same amount every time” is the secret of the whole chapter. Hold on to it.

2

What an AP is

An arithmetic progression (AP) is a list of numbers where each number is made by adding the same fixed number to the one before it.

Term
Each number in the list. We call them a1, a2, a3 and so on. The small number tells you its place in the line.
First term, a
The number you start from.
Common difference, d
The fixed amount you add every time. “Common” means shared: every pair of neighbours has this same difference.

d can be any number. It decides which way the staircase goes:

Going up

d = 4, a positive number

Going down

d = −5, a negative number

Staying flat

d = 0, nothing changes

Fractions and decimals are fine too. 1.5, 2, 2.5, 3 is an AP with d = 0.5.

Find the jump

To find d, take any term and subtract the term just before it.

d = a2 − a1 = a3 − a2 = …later term minus the earlier term

Always do later minus earlier. If you subtract the other way round, you get the right size but the wrong sign.

Find d for 4, 10, 16, 22, …

  1. d = 10 − 4 = 6
  2. Check another pair: 16 − 10 = 6. Same answer, good.

d = 6

Find d for −1, −3, −5, −7, …

  1. d = (−3) − (−1)
  2. = −3 + 1  (minus a minus becomes plus)
  3. = −2

d = −2. The numbers are going down, so d had to be negative.

Check at least two pairs. If you get different answers, the list is not an AP.

4

Write an AP

If you know where to start (a) and how big each jump is (d), you can write the whole AP:

a,  a + d,  a + 2d,  a + 3d, …

Think of a frog on a number line. It starts on a, and every hop is exactly d long. Press the button and count the hops.

The frog: a = 3, d = 4

Here is the big idea. To land on term 5, the frog made 4 hops, not 5. The first term needs no hops at all, because the frog starts there. So:

The number of jumps is always one less than the term number. Term n needs (n − 1) jumps.

Write the first four terms when a = 4 and d = −3

  1. a1 = 4
  2. a2 = 4 + (−3) = 1
  3. a3 = 1 + (−3) = −2
  4. a4 = −2 + (−3) = −5

4, 1, −2, −5

Any term, fast

What if you want the 100th term? Hopping 99 times is boring. Use the jump rule from Step 4 instead: start at a, then add (n − 1) jumps of size d.

an = a + (n − 1)dthis is called the nth term or general term

Try the formula

    Finding a term

    Find the 10th term of 2, 7, 12, …

    1. a = 2,  d = 7 − 2 = 5,  n = 10
    2. a10 = 2 + (10 − 1) × 5
    3. = 2 + 9 × 5 = 2 + 45

    a10 = 47

    Finding which term

    Which term of 21, 18, 15, … is −81?

    1. a = 21,  d = −3, and we want an = −81
    2. −81 = 21 + (n − 1)(−3)
    3. −81 − 21 = (n − 1)(−3), so −102 = (n − 1)(−3)
    4. n − 1 = −102 ÷ −3 = 34

    n = 35, so −81 is the 35th term.

    Checking if a number belongs

    Is 301 a term of 5, 11, 17, 23, …?

    1. a = 5,  d = 6
    2. 301 = 5 + (n − 1) × 6, so 296 = (n − 1) × 6
    3. n − 1 = 296 ÷ 6 = 49.33…

    n is not a whole number, so 301 is not a term.

    A term's place in the line is always a counting number: 1st, 2nd, 3rd… There is no “50.33rd” term.

    Counting how many

    How many two-digit numbers can be divided by 3?

    1. They are 12, 15, 18, …, 99. This is an AP with a = 12, d = 3.
    2. The last one is 99, so 99 = 12 + (n − 1) × 3
    3. 87 = (n − 1) × 3, so n − 1 = 29

    n = 30 numbers

    When two terms are given

    The 11th term is 38 and the 16th term is 73. Find the 31st term.

    1. a + 10d = 38  and  a + 15d = 73
    2. Subtract the first from the second. The a's cancel: 5d = 35, so d = 7
    3. Put d back: a + 70 = 38, so a = −32
    4. a31 = −32 + 30 × 7 = −32 + 210

    a31 = 178

    Count from the end

    Sometimes a question asks for a term counted from the last one. Easy: turn around. Start on the last term l and jump backwards, which means taking away d each time.

    nth term from the end = l − (n − 1)dl is the last term

    Find the 20th term from the last of 3, 8, 13, …, 253

    1. l = 253,  d = 5,  n = 20
    2. 253 − (20 − 1) × 5 = 253 − 95

    Add them all up

    About 250 years ago, a teacher wanted to keep his class busy. He said, “Add up every number from 1 to 100.” A small boy named Carl Friedrich Gauss gave the answer almost at once: 5050.

    His trick was to pair the numbers from both ends:

    1. 1 + 100 = 101
    2. 2 + 99 = 101
    3. 3 + 98 = 101, and so on.

    Every pair makes 101. 100 numbers make 50 pairs. So the total is 50 × 101 = 5050.

      The rectangle is n columns wide and (first + last) tall. Two copies of the sum fill it, so one sum is half the rectangle:

      Sn = n⁄2 (a + l)use this when you know the last term l

      If you don't know l, swap it for the nth term formula, l = a + (n − 1)d:

      Sn = n⁄2 [2a + (n − 1)d]the sum of the first n terms

      Find the sum of the first 22 terms of 8, 3, −2, …

      1. a = 8,  d = −5,  n = 22
      2. S22 = 22⁄2 [2 × 8 + (22 − 1)(−5)]
      3. = 11 [16 − 105] = 11 × (−89)

      S22 = −979

      Find the sum of the first 1000 positive whole numbers

      1. 1, 2, 3, …, 1000. Here a = 1, l = 1000, n = 1000
      2. S = 1000⁄2 × (1 + 1000) = 500 × 1001

      S = 500500

      A harder one

      How many terms of 24, 21, 18, … add up to 78?

      1. a = 24, d = −3. We want Sn = 78
      2. 78 = n⁄2 [48 + (n − 1)(−3)] = n⁄2 [51 − 3n]
      3. 156 = 51n − 3n², so 3n² − 51n + 156 = 0
      4. Divide by 3: n² − 17n + 52 = 0, which factors as (n − 4)(n − 13) = 0

      n = 4 or n = 13. Both are correct.

      Why two answers? Terms 5 to 13 are 12, 9, 6, 3, 0, −3, −6, −9, −12, and they add up to zero. So adding them doesn't change the total.

      A handy trick: a term from two sums

      The sum of 5 terms minus the sum of 4 terms leaves only the 5th term. So:

      an = Sn − Sn−1

      If Sn = 4n − n², find the AP

      1. S1 = 4 − 1 = 3, so a1 = 3
      2. S2 = 8 − 4 = 4, so a2 = S2 − S1 = 1
      3. d = 1 − 3 = −2

      The AP is 3, 1, −1, −3, …

      The last two rows are shortcuts. For “three numbers in AP add up to 24”, call them a − d, a, a + d. Adding them gives 3a = 24, so the d's vanish and a = 8 straight away.

      Mistakes to avoid

      • a10 = a + 10da10 = a + 9d. Ten terms need only nine jumps.
      • For 10, 7, 4: d = 10 − 7 = 3d = 7 − 10 = −3. Later minus earlier.
      • 21 + 34 × −3 = 21 + 10221 + 34 × (−3) = 21 − 102 = −81. Keep negative d in brackets.
      • n = 49.33, so it's roughly the 49th termn must be a whole, positive number. If not, the number isn't in the AP.
      • Using an when the question says “sum”an is one term. Sn is the total of the first n terms.
